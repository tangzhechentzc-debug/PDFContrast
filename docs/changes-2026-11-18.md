# 2026-11-18 改动与验证记录

## 改动范围

| 改动 | 代码位置 | 行为及边界 |
| --- | --- | --- |
| 造价报表业务比较 | `backend/cost_reports.py`、`backend/pdf.py`、`backend/reports.py` | D.1/D.2/D.3 汇总及 E.1 清单按业务字段比较；数字用 Decimal，编码保留前导零，无法可靠提取或匹配时列为待核对。详见 [业务比较说明](cost-report-comparison.md)。 |
| 大册 PDF 处理 | `backend/pdf.py`、`backend/pdf_assets.py`、`backend/models.py` | 移除整册页数、累计像素及整册格数截断；大册外观证据逐页压缩存储并按报表加载释放，原页图像按需缓存。仍保留每份 50 MB、单页预算和 5000 组配置上限。 |
| PDF 外观与来源定位 | `backend/pdf_appearance.py`、`backend/reports.py` | 复用表格识别结果和几何证据，调整页面对应、文字、段落、表格、矢量及视觉残差比较。 |
| 接口和修订处理 | `backend/app.py`、`backend/review.py` | 精简公开页面元数据，段落检查分页返回；减少重复加载及数据库写锁内的处理，继续校验修订冲突。 |
| 前端交互 | `frontend/src/components/`、`frontend/src/api.ts`、`frontend/src/types.ts` | 增加业务数据筛选与状态、段落检查分页、折叠配置按需加载；调整差异定位、原页图像加载与重试。 |
| Excel 比较 | `backend/compare.py`、`backend/excel.py`、`requirements.txt` | 原生字典匹配替代 DataComPy，移除 pandas/DataComPy 依赖；调整格式比较的默认样式处理。 |
| 导出 | `backend/export.py`、`backend/app.py` | 导出实现独立成模块，包含业务差异及验证范围；长证据按有序 JSON 片段输出，规则页超出 Excel 行数限制时续页。 |
| 启动与 Windows 打包 | `run.sh`、`packaging/windows/`、`scripts/build-windows.ps1` | 启动时按哈希复用依赖及前端产物；新增 Windows 构建、安装及启动器，支持独立数据目录。详见 [Windows 安装说明](windows-install.md)。 |
