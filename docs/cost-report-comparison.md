# 工程造价报表业务数据比较

支持 D.1 建设项目汇总、D.2 单项工程汇总、D.3 单位工程费用汇总和 E.1 分部分项清单。导入两份 PDF 后，确认报表对应关系并执行比较，在“业务数据”维度查看变化；选择记录会定位两侧原页单元格。Excel 导出包含“业务数据差异”和业务字段验证范围。

## 接入方式

`backend/cost_reports.py` 移植 PDFAnalysis 的四类表头字段规则与 E.1 多行表头识别规则，作为本项目自包含的适配模块。没有运行时外部仓库路径或 exe 依赖，也没有引入第二套 PDF 渲染。业务数据来自现有物理表格及其 `pdf_source`；比较使用当前人工修订后的单元格。原始 PDF、提取数据和历史修订不改写。

现有完整报表的内容、结构、格式、版式比较继续保留。业务数据单列 `category=business`，数值写法 `10.00` 与 `10.0` 相同；原文维度仍可报告写法变化。因此全部事件数可能包含同一修改在原文和业务两个层面的记录，应使用类别筛选查看。

## 比较与证据规则

- D.1/D.2 按工程名称，D.3 按汇总内容，在已确认报表内部对应；E.1 按项目编码对应。编码保留前导零，行重排不构成增删。续页从报表成员物理表收集，避免重复读取逻辑汇总表。
- 工程量、单价、金额等使用 Decimal，差额为新版减旧版，容差为零。空白不等于零。名称、特征、计量单位等比较业务文字，空白排版差异由原文维度保留。
- 汇总表保留总计行，不根据缺失总计推算“原文总价”。E.1 的章节与小计行不作为清单项。
- 字段差异携带原页、单元格及区域；新增/删除缺席侧不伪造来源。提取问题仅提供明确标记的参考区域。
- 缺字段、未知列、空键、重复键、续表字段不一致、非法数值、未核验 OCR、失败页和未确认结构均为待核对，不输出“业务一致”。仅按顺序/剩余实例自动配对或重复工程身份的报表，需人工确认后才比较业务数据。D.2 限价与报价不自动视为同类业务报表。

## 接口

完整 PDF 比较结果的 `reports[*].business` 包含 `status`（`changed/unchanged/pending`）、`compared_rows`、`compared_fields`、`changes`、`issue_count`、`issues`。

业务差异沿用现有差异接口，新增类型为 `business_value_changed`、`business_row_added`、`business_row_removed`、`business_issue`。`GET /api/runs/{id}/diffs?category=business` 可筛选；原页查看器与普通差异共用来源契约。

## 验证与范围

`tests/test_cost_reports.py` 覆盖数值等价、前导零、跨页、行重排、重复键、缺字段、OCR 和归属歧义等；`tests/test_cost_report_integration.py` 生成四页中文 PDF，经真实提取、导入 API、比较、来源检查及 Excel 导出验证完整路径。

现支持整册导入，不再以 100 页、累计像素或整册格数作为截断条件。大册完整外观证据逐页压缩存盘、按当前报表读取后释放，144/288 dpi 原页按需渲染并缓存；保留单页资源预算、每份 50 MB 及 5000 组比较配置上限。仍需足够的本机内存和磁盘。

大册配置项展开时加载；页面和表格公开元数据不携带内部文字或几何证据。段落测量明细按报表分页读取，完整运行快照保留；导出将长测量证据拆为有序JSON片段，规则页达到Excel行数上限时续页，不截断检查记录。

真实表型支持跨行工程名、D.1/D.2 父级工程来源、合并首列中的总计、D.3 层级子项、E.1 三/四位章节码及被拆分的金额表头，并比较不可竞争费、定额人工费/机械费和暂估价。限价与报价作为不同报表族。未加入 H.3/H.4/E.2 的专用业务字段比较，这些页面仍保留现有完整报表比较。

跨格式 PDF/Excel 比较、自动金额勾稽和规范符合性判定不在本次范围。历史结果不会自动新增业务记录，需重新执行比较；旧提取未识别表号或工程名时可重新处理原件。真实整册验证证据见 [整册验证记录](../output/whole-book-validation/report.md)。
