# PDF 完整业务报表比较（版本 2）

`report_inventory_version: 2` 将完整业务报表作为比较对象。封面、扉页、说明、数据表、空白表单都能参与比较，不要求存在规则网格或非空数据行。版本 1 的字段比较门槛仅用于旧数据与旧运行；新任务通过重新处理原件生成，原文件、提取快照与核验历史不改写。

## 报表对应关系

优先按报表编号、标题和章节建立对应。同类型唯一报表可在工程名称、日期、表头、页面方向不同的情况下对应，这些变化属于比较结果。重复类型再依据对象和上下文区分；仍有歧义时保留候选，允许人工选择并填写依据。明确不同类型不能自动强配。提取失败不能证明报表缺失。

`PairConfig.old_report_id / new_report_id` 指向完整报表；`old_sheet / new_sheet`、列映射和业务键保留给旧版与 Excel 使用。新 PDF 不以这些字段作为完整报表比较的前置条件。

`BusinessReport.comparison_regions` 保存完整对象在各物理页上的归属范围。单报表页包括标题、工程名称、正文、表框、签章区、注释与页眉页脚；同页多报表按各自标题边界分区。既有 `regions` 仍可表示表体片段，不冒充完整比较范围。

## 提取与证据

原生文字、区域 OCR 与人工校正分别保留来源。`pages[].appearance` 保存服务端比较所需的原生绘制属性、几何和统一渲染证据；大体积细节不随常规 job/run API 返回。页面公开元数据提供 `physical_width / physical_height`（PDF 点）、原始 MediaBox/CropBox、旋转和渲染图大小。

匹配可使用归一化文字与几何辅助，但最终结果保留实际文字、标点、填写值和原始尺寸。原始版式比较不通过拉伸、旋转或裁白边消除横竖版、边距或整体位置差异。查看器的显示缩放不参与服务端比较。

版本 2 固定执行四类比较，格式不再是可关闭的选项。兼容网格仍利用业务键和 Decimal 给出跨页字段差额；同时比较原文写法，不因数值相等而隐藏小数位、分隔符或填写表现的变化。Excel 的数值容差和可选格式规则保持原有行为。

## 每张报表的四类结果

`Run.reports[].dimensions` 包含 `content / structure / format / layout` 四键。每项记录：

- `status`：`changed / unchanged / partial / unverified / not_applicable`。
- `changes / issues`：确定变化与待核验事件数。
- `summary / limitations`：比较结论及不可验证属性。

`unchanged` 只适用于实际覆盖的属性，不表示未支持属性已验证。扫描图像不能直接确定字体名、字号等原生属性；以可验证视觉变化或未验证项报告。

`page_pairs` 固定两侧物理页对应关系、依据和 `confirmed / pending` 状态。前端不得通过相同页号或数组索引重新猜配。`change_count` 是该报表所有类别的确定变化数；`comparison_status=changed` 包括仅版式发生变化的情况。

每条差异带 `report_id`、`category` 与两侧原文位置。`category` 为四类之一或 `completeness`；`layer` 同类别，待核验事件使用 `uncertainty`。`GET /api/runs/{id}/diffs` 支持 `report_id`、`category`、`layer` 联合筛选，服务端先过滤再计数分页。

## 显示、导出和历史

结果以每张报表展示四类摘要与完整原页。并排、切换或叠加查看使用共同比例，保留不同物理纸张大小及空余范围；显示比例不等于显示器真实毫米尺寸。

导出使用同一 run 快照，包含四类差异、报表完整性、属性验证范围、原页对应、待核对与审核历史。旧 run 缺少新字段时显示当次未计算，不能用当前提取结果补写其结论。

文字核验、结构核验与格式可验证性分别处理。版本 2 的 OCR 说明页可以核验文字，不必先重建成网格；这不会把未知字体或未确认行列结构变成已验证。

## 当前属性覆盖与边界

| 范围 | 已实现的比较 | 未验证或不能推断的内容 |
|---|---|---|
| 原生文字 | 实际原文、标点、填写与清空；局部空白及同文换行；兼容网格按业务键保留精确差额 | OCR 失败不是空白；未核验 OCR 只提供待确认文字证据 |
| 字体与文字格式 | 去子集前缀后的 PDF 字体资源、可可靠提取的有效字号、可确认粗细、文字颜色、实际字距、段落有效基线行距与可证几何对齐 | 原编辑器字体设置与加粗开关；旋转字符包围框不能可靠反推字号 |
| 表格和空白表单 | 可恢复矢量网格的行列、跨度与合并；闭合框、填写线、局部边框样式与填充色 | 复杂无框表和扫描网格不自动认定结构可靠 |
| 原始版式 | 物理尺寸、横竖方向、Rotate、内容旋转、裁切范围、文字和框线位置、行高列宽分割、图像位置与分页 | 段落设置无法反推；行距与对齐按下述证据范围单独验证。签章区不作语义识别，借助区域几何提示变化 |
| 视觉证据 | 统一渲染尺度，保留 RGB；对扫描及混合图像区域使用轻度模糊、边缘容差和变化区域聚合 | 不从扫描图像编造字体名、字号；视觉提示需复核，不判断签章真实性 |
| 复杂 PDF 对象 | 保留可见渲染与原始位置，发现注释、Widget 或可选层时列出限制 | 交互状态、隐藏层、复杂透明混合、ICC/专色及任意曲线路径未完整逐属性解析 |

“未发现变化”只针对实际覆盖的证据与检测精度。界面与导出始终保留各维度的限制说明；待确认和部分可比不得替换为完整一致。

## 段落有效行距与左／中／右对齐

运行快照中的 `reports[].paragraph_checks` 按实际段落与属性记录 `changed / unchanged / unverified`，包含两侧原页区域、描述和 `measurements`。属性为 `line_spacing` 或 `alignment`。公开的创建、读取与历史列表接口只返回 `paragraph_check_summary`（`total / changed / unchanged / unverified`），避免整册测量明细阻塞结果页面。展开检查后调用 `GET /api/runs/{id}/paragraph-checks?report_id=...&offset=0&limit=100`，响应为 `items / total / offset / limit`；每页最多100条，保留判定、说明和两侧来源，不传原始 `measurements`。分页不修改内部完整快照，导出「段落测量证据」仍保存当次运行的测量值、位置和依据。历史运行没有检查记录时显示“本次未记录”，不补写新结论；前端兼容旧接口内联的检查记录。

- 行距由原生字形矩阵的基线坐标乘以 UserUnit 后计算相邻距离，单位 pt；整块平移不会改变距离。
- 页面尺寸、字号和内容缩放同时变化时，仍报告可测的实际距离变化；这些伴随变化保存在测量上下文中，不将结果说成编辑器的固定值或倍数设置变化。
- 对齐使用不同长度文字行唯一稳定的左边、中心或右边，以及可靠单元格／闭合框参考。单行只在明确边界和唯一对齐证据成立时判定，不假定未知内边距。
- 不同单元格、独立字段、编号列表项分别处理；字段间距或段间距不冒充段内行距。
- 等宽行、单行无可靠参考、换行／缺字导致对应不完整、旋转或扫描文字等不能可靠测量时，逐项标为未验证；页面未分段范围汇总说明。

确定变化使用 `paragraph_line_spacing_changed` 与 `paragraph_alignment_changed`，归入格式差异；待核验变化汇总为 `paragraph_measurement_unverified`。原始字体、边框与页面几何比较继续独立保留。
